# 🎯 27届秋招备战中心

一个纯静态的秋招信息汇总网站，帮你集中管理**互联网行业**的目标公司、秋招时间线，以及**产品 / 产运 / 商分 / 战略 / 数分**五个岗位方向的准备资料。

## 功能

- **📊 概览**：秋招时间线（27届聚焦 2026 下半年）+ 各岗位机会数量分布
- **🏢 公司机会**：15 家目标公司卡片，支持按「岗位 / 公司层级」筛选；每家可下拉更新投递状态（想投→已投→笔试→各轮面试→Offer），状态自动保存在浏览器本地
- **📚 准备方向**：每个岗位的核心能力、准备重点、高频面试题、推荐资源
- **✅ 我的进度**：通用备战 checklist，勾选进度带进度条，自动保存

## 如何启动

由于用到了 `localStorage`，建议用本地服务器打开（直接双击 HTML 部分浏览器也能用）：

```bash
cd "/Users/bytedance/Desktop/trae_projects/00-27秋招"
python3 -m http.server 8000
```

然后浏览器访问 http://localhost:8000

## 如何维护数据

**所有内容都在 `data.js` 一个文件里**，改完刷新页面即可，无需动其他文件：

- `TIMELINE` — 秋招时间线节点
- `COMPANIES` — 公司机会（新增一家就复制一个 `{}` 块）
- `PREPARATION` — 各岗位准备方向
- `CHECKLIST` — 备战清单条目

字段说明写在 `data.js` 顶部注释里。
