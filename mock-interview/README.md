# Mock · 结构化模拟面试

一个无需登录即可使用的浏览器端模拟面试工具。系统按岗位题包推进问题，根据回答中缺失的信息触发追问，并生成带证据的本地复盘。

## 当前能力

- 腾讯产品经理综合面经、通用 AI 产品经理两个题包。
- 15 / 30 / 45 分钟面试计划，支持温和、标准、深入三档追问。
- 规则化动态追问：每道主问题最多追问两次。
- 腾讯综合面经覆盖 50 条来源问法，去重为 12 组母题，并按场次组合为自然面试流程。
- 六维本地文本评估：内容完整度、表达结构、证据具体度、个人贡献、复盘成长、问题相关度。
- IndexedDB 保存会话、逐题回答和草稿；不支持时自动降级。
- 刷新恢复、暂停、提前保存退出、历史趋势、逐题重答。
- Markdown 单场报告与 JSON 全量备份。
- 所有腾讯综合面经主问题及追问均含回答框架与参考答案；内容仅在完成后的复盘页和导出报告中展示，不在作答前泄露。
- 浏览器语音转写渐进增强；不支持时完整回退到文字输入。

## 本地运行

在仓库根目录执行：

```bash
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/mock-interview/`。

## 隐私与评分边界

- 候选人背景、转写文本、会话和报告默认只保存在当前浏览器。
- 本站不保存原始音频；使用 Web Speech API 时，音频可能由浏览器厂商在线处理。
- 本地评分只分析文字中的结构、关键词和可观察证据，不能验证经历真实性，也不代表招聘结论。
- 网站没有模型 API，也不需要在前端填写密钥。

## 技术结构

- `index.html`：四个主视图与无障碍结构。
- `styles.css`：响应式视觉系统。
- `js/question-packs.js`：公开、脱敏的题包和追问信号。
- `js/storage.js`：IndexedDB 与降级存储。
- `js/engine.js`：面试计划、规则评分、追问选择与报告导出。
- `js/voice.js`：浏览器语音识别和语音合成能力封装。
- `app.js`：状态机、界面渲染与完整用户流程。
